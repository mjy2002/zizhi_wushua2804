

广播命令帧

| CAN ID  | 名称                | 方向      | DLC  | 数据字段 | 类型 | 单位 | 说明                                                         |
| ------- | ------------------- | --------- | ---- | -------- | ---- | ---- | ------------------------------------------------------------ |
| `0x000` | 全局同步执行 / 启动 | 主机->从机 | 0    | 无       | -    | -    | 唯一全局同步触发点。有缓存命令则执行缓存命令；无缓存命令则启动电机并保持当前位置 |
| `0x001` | 全局停止电机        | 主机->从机 | 0    | 无       | -    | -    | 所有电机立即停止，关闭驱动输出，锁定当前位置，清除所有同步缓存 |
| `0x003` | 全局清除同步缓存    | 主机->从机 | 0    | 无       | -    | -    | 清除所有电机中缓存的未执行同步命令，不影响当前正在运行的电机状态 |

电机 1 控制命令帧

| CAN ID  | 名称             | 方向      | DLC  | 数据字段         | 偏移    | 类型        | 单位       | 说明                                                         |
| ------- | ---------------- | --------- | ---- | ---------------- | ------- | ----------- | ---------- | ------------------------------------------------------------ |
| `0x200` | 速度模式控制     | 主机->从机 | 5    | 目标转速同步标志 | 0-3 4.0 | float32 bit1 | rad/s      | 切换速度模式。同步标志 = 0：立即启动电机运行；同步标志 = 1：仅缓存目标转速，等待 0x000 全局同步触发后启动。字节 4 的 bit1-bit7 保留，必须置 0 |
| `0x201` | 位置模式控制（绝对式/增量式合并） | 主机->从机 | 5 | 目标位置 同步标志 位置类型标志 | 0-3 4.0 4.1 | int32 bit1 bit1 | 编码器计数 | 切换位置模式。位置类型标志 = 0：绝对式，目标位置为绝对编码器计数值；位置类型标志 = 1：增量式，目标位置 = 当前位置 + 增量值。同步标志 = 0：电机按限速立即运行到位；同步标志 = 1：仅缓存，等待 0x000 全局同步触发后运行。字节 4 的 bit2-bit7 保留，必须置 0 |
| `0x202` | 请求状态反馈     | 主机->从机 | 0    | 无               | -       | -           | -          | 触发从机上报 0x204、0x205、0x207 状态帧                      |
| `0x203` | 位置模式限速设置 | 主机->从机 | 4    | 位置最大限速     | 0-3     | float32     | rad/s      | 单独配置位置环 PID 速度限幅值，全局生效控制位置运行最大速度  |
| `0x206` | 清除本地同步缓存 | 主机->从机 | 0    | 无               | -       | -           | -          | 仅清除电机 1 中缓存的未执行同步命令，不影响当前运行状态      |
| `0x208` | ~~增量位置模式控制~~ | - | - | - | - | - | - | 已废弃，增量式位置已合并至 0x201（byte4 bit1 = 1） |

电机 1 状态反馈帧

| CAN ID  | 名称       | 方向      | DLC  | 数据字段             | 偏移        | 类型         | 单位             | 说明                                                         |
| ------- | ---------- | --------- | ---- | -------------------- | ----------- | ------------ | ---------------- | ------------------------------------------------------------ |
| `0x204` | 主状态帧   | 从机->主机 | 8    | 当前位置当前速度     | 0-3 4-7     | int32 float32 | 编码器计数 rad/s | 包含位置和速度信息                                           |
| `0x205` | 电流状态帧 | 从机->主机 | 2    | Q 轴电流             | 0-1         | int16        | mA               | 仅包含 Q 轴电流，已做饱和处理（+-32767）                      |
| `0x207` | 同步状态帧 | 从机->主机 | 1    | 同步缓存状态运行模式 | 0.0 0.1-0.2 | bit1 bit2     | -                | bit0：同步缓存状态（1 = 有未执行的同步命令，0 = 无）；bit1-bit2：运行模式（00 = 停止，01 = 速度模式，10 = 位置模式）；bit3-bit7 保留 |
